# 65kgへの道 PWA v2

筋トレメニュー画面を追加。火曜・金曜の予定、6種目の回数・フォーム・注意点、日付ごとの完了チェックに対応。

## 更新方法
GitHubの `65kg-tracker` リポジトリのルートへ、このZIPの**中身**を上書きアップロードしてコミットしてください。ZIPそのものはアップロードしないでください。公開反映後、スマホのアプリを終了して再起動してください。古い画面なら再読み込みを行ってください。

## データ
既存の体重・食事記録は `health65.entries.v1` に保存され、そのまま保持されます。筋トレチェックは `health65.workout.v2` に保存されます。JSONバックアップには筋トレチェックも含み、旧バージョンのJSONも復元できます。

**更新前に、アプリの設定画面からJSONバックアップを保存してください。** サイトデータ削除や別のブラウザ・端末では記録が引き継がれません。
