# 65kgへの道 PWA v2.1

筋トレ6種目と記録機能はv2と同じです。v2.1では、アプリを再起動した際に古い画面に戻る問題を改善しました。

## 更新方法

1. **スマホのアプリで設定 → バックアップ(JSON)を保存**。
2. このZIPを展開し、中のファイルと `icons` フォルダーをGitHubの `65kg-tracker` リポジトリのルートへ上書きアップロード。ZIPそのものはアップロードしない。
3. GitHub Pagesの公開完了を待つ。
4. スマホのChromeで `https://sanbow2022.github.io/65kg-tracker/?v=21` を開き、筋トレタブを確認。
5. ホーム画面のアプリを完全に終了して再起動。初回は2回起動が必要な場合があります。

**注意**: アンインストール、アプリデータ削除、サイトデータ削除はしないでください。既存の体重記録は従来と同じ `localStorage` キーを使用します。
