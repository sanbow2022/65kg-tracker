# からだログ v3（65kgへの道の更新版）

友人と共有できる初回設定・プロフィール編集機能を追加しました。

## 更新
1. 旧アプリの設定からJSONバックアップをダウンロード。
2. ZIPを展開して中身すべてをGitHubリポジトリのルートにアップロード（既存ファイルを更新）。
3. GitHub Pagesの公開完了後、Chromeで `?v=30` を付けて確認し、ホーム画面のPWAを再起動。
4. 設定→自分のプロフィールで名前・年齢・身長・歩数目標・運動曜日・筋トレ曜日・食事・飲み物の目標を編集。

## 保存とプライバシー
データはブラウザ/インストールしたPWAのlocalStorageに保存。別端末とは同期されません。URLを友人に送っても記録は共有されません。同一端末・同一ブラウザで複数人の使い分けには非対応。
既存の `health65.entries.v1` / `health65.settings.v1` / `health65.workout.v2` はそのまま維持します。JSONバックアップにはプロフィールも含みます。

## 公開用の確認・補正（2026-10-26）
- 保存キー、公開パス、PWAのstart_url・scopeを維持。
- 初回設定中にヘッダー・ナビが表示されないようhidden属性を優先。
- 自由入力のプラン表示をHTMLエスケープ。
- 旧JSONバックアップの復元時に従来の運動・食事設定を保持。
- 旧記録の読込、初回設定、体重・筋トレ保存と再読込、旧JSON復元、v3 JSON書出をコード検証済み。
- GitHub Pagesへの反映と公開後の画面操作・スマホ表示は未確認。

## 更新時のバックアップ
既存アプリの「設定」→「バックアップ(JSON)」を選び、65kg-backup.jsonを端末に保存してください。CSVだけでは筋トレチェックを復元できません。アプリの削除やブラウザのデータ消去は不要です。同じ端末・ブラウザ・公開URLで開いてください。記録が見えない場合は入力せず、バックアップを確認してください。
