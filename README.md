# 65kgへの道 — 個人用PWA v1

## 内容
- 毎日の曜日別プラン（ゴルフ・筋トレ・食事）
- 体重、歩数、ゴルフ分数、筋トレ、豚骨ラーメン、スープ、夕食、ビール、メモの記録
- 体重推移・7日移動平均グラフ、直近7日間の集計
- CSVエクスポート、JSONバックアップ／復元
- ブラウザのlocalStorageへの端末内保存（クラウド同期なし）
- HTTPS配信時のインストール・オフライン起動

## 起動方法
PCで簡易確認: このフォルダ内で `python -m http.server 8000` を実行し、http://localhost:8000 を開く。
Androidにインストール: このフォルダ内のファイルをそのままHTTPS対応の静的ホスティング（GitHub Pages等）へ配置し、Chromeで公開URLを開き「アプリをインストール」を選ぶ。

## 重要
- `index.html` を端末上で直接開いただけではPWAインストールやオフラインキャッシュが有効にならない。
- 保存は端末・ブラウザ・公開URLごと。ブラウザデータ消去やサイトURL変更で記録が消える場合がある。定期的にJSONバックアップする。
- 通知はこのアプリ内には未実装。既存のChatGPT朝7時タスクを利用する。
- 公開ホスティングを利用しても、入力した記録はサーバーに送信しない。ただし公開URL自体は他人からアクセスできる場合がある。
